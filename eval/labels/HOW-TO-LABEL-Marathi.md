# Labelling चे नियम — हे एकदा वाचून मगच सुरू कर

**फाईल:** `eval\labels\run5-skill-verification-labels.csv` · **४२ ओळी**
**Brief:** Senior Backend Engineer · 4–7 वर्षं · **Python, Django, AWS** · Bangalore

---

## का हे महत्त्वाचं आहे

मागच्या वेळी २८ पैकी **४ labels तुझ्याच नोट्सच्या विरुद्ध** होते. त्यामुळे आपण code तपासतोय की उत्तरपत्रिका, हेच कळत नव्हतं — आणि `top 20` खराब झाल्यासारखा दिसत होता, जे खोटं होतं.

**तू जे ठरवशील ते बरोबर.** फक्त **सगळ्यांना एकच नियम** लाव.

---

## फक्त पहिला column भर

| लिही | अर्थ |
|---|---|
| `g` | या जागेसाठी **संपर्क करण्यासारखा** आहे |
| `b` | **नाही** |
| `?` किंवा रिकामं | ठरवता येत नाही — **वगळलं जाईल**, अंदाजाने भरू नकोस |

बाकी columns ला हात लावू नकोस. मधेच थांबलास तरी चालेल — रिकाम्या ओळी वगळल्या जातात.

---

## क्रमाने हे ४ प्रश्न विचार

### १️⃣ Location — भारताबाहेर आहे का?

**बाहेर असेल → `b`. संपलं.** (तुझाच नियम)
भारतात कुठेही (Pune, Chennai, Vellore, Hyderabad…) → **पुढे जा**
Location दिसतच नाही → **पुढे जा**, फक्त यावरून `b` करू नकोस

### २️⃣ Role — हा खरंच backend engineer आहे का?

Frontend / QA / Data Analyst / DevOps / Manager-only → `b`
Recruiter किंवा "hiring for" पोस्ट → `b`

### ३️⃣ Stack — Python / Django चा आहे का?

Profile उघडून बघ. **Java, .NET, PHP, Node** चा असेल आणि Python कुठेच नसेल → `b`
दोन्ही असतील → `g` चालेल

### ४️⃣ Experience — 4–7 वर्षांच्या आसपास आहे का?

खूप junior (0–2 वर्षं) किंवा खूप senior (१२+, Director/VP) → `b`
थोडं मागे-पुढे (३ किंवा ८) → **`g` चालेल**, ही कडक मर्यादा नाही

## दोन महत्त्वाच्या सूचना

**🔓 URL उघड.** Headline वरून नेहमी कळत नाही. संशय असेल तर profile उघडूनच बघ.

**🚫 Score किंवा rank शोधू नकोस.** फाईलमध्ये मुद्दाम ठेवलेले नाहीत. ॲपने त्याला किती गुण दिले हे बघितलंस की तू नकळत त्याच्याशी सहमत होशील — आणि मग हे मोजमाप फक्त स्वतःलाच बरोबर ठरवेल, काहीच नवीन सांगणार नाही.

**तू ॲपची तपासणी करतोयस. ॲप तुला उत्तर सांगणार नाही.**
